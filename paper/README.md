# Peekaboo: the paper

`main.tex` (arXiv-style LaTeX), `refs.bib`, and everything generated from the results:

    python paper/make_figures.py          # figures/*.pdf, tables_*.tex, numbers.tex, numbers.json  (from experiments/peekaboo_remaining/output)
    cd paper && tectonic main.tex         # main.pdf (or pdflatex + bibtex)

Every number in the text comes from `numbers.tex` (macros) or `tables_*.tex`; both are regenerated by `make_figures.py`
with VegaML's own metric code, so the paper cannot drift from the results. For arXiv, upload `main.tex`, `refs.bib`,
`numbers.tex`, `tables_*.tex`, `main.bbl` and `figures/`.
